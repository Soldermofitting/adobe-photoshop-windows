## Системные требования (ориентир для Photoshop 2026)

| Компонент | Минимум | Комфортная работа |
| --- | --- | --- |
| ОС | Windows 10 x64 | Windows 11 x64 |
| ОЗУ | 8 ГБ | 16–32 ГБ (крупные PSD, Neural Filters) |
| Диск | SSD от 10 ГБ свободно под программу | SSD + отдельный диск под кэш и архивы проектов |
| GPU | DirectX 12, 2 ГБ VRAM | 4+ ГБ VRAM для тяжёлых фильтров |
| Экран | 1280×800 | 1920×1080 и выше, калибровка для печати |

Для **Premiere** или **After Effects** в той же связке смотрите требования на их карточках в каталоге — видео тянет больше RAM и место на диске.

## Рабочие советы (без воды)

- **Слои и маски** — не flatten, пока макет не утверждён; Smart Object для нерушимой трансформации.
- **Camera Raw** — правьте экспозицию до пиксельной ретуши; так меньше артефактов на коже и неба.
- **Цвет** — для печати держите документ в CMYK или согласованном ICC-профиле типографии; для web — sRGB.
- **Автосохранение** — включите в настройках и задайте частый интервал на слабом SSD.
- **Scratch disk** — вынесите на быстрый SSD, не на системный диск под завязку.

## Полезные сочетания клавиш (Windows)

| Действие | Клавиши |
| --- | --- |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Свободное трансформирование | `Ctrl+T` |
| Новый слой через копию | `Ctrl+J` |
| Сохранить для web | `Ctrl+Shift+Alt+S` |
| Масштаб по экрану | `Ctrl+0` |
| Пипетка | `Alt` (с кистью) |
